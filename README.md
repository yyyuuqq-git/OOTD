# 🎓 CampusFit (캠퍼스핏) - 등하교 날씨 & 스마트 OOTD 코디 추천 웹페이지

> **GPS 기반 실시간 기상 데이터 분석** 및 **대학생 등하교 시간표(월·목 vs 수·금) 맞춤형 옷차림 코디 가이드**

---

## 🌟 핵심 기능 요약

### 1. 📡 GPS 실시간 위치 & 대학가 프리셋
- **원클릭 GPS 탐색**: 브라우저의 Geolocation API를 통해 현재 위치 좌표를 가져와 실시간 날씨를 조회합니다.
- **역지오코딩 (Reverse Geocoding)**: 좌표를 한글 행정구역명(예: `서울특별시 서대문구 신촌동`)으로 자동 변환합니다.
- **주요 대학가 프리셋**: GPS 권한을 허용하지 않더라도 신촌(연세·이화·서강), 혜화(성균관), 안암(고려), 관악(서울), 왕십리(한양), 수원, 대전(KAIST·충남대), 부산 등 16개 이상 주요 대학가 및 도시를 원클릭으로 선택할 수 있습니다.

### 2. 🎯 등하교 3대 핵심 시간대 정밀 분석
대학생의 하루 등하교 일정에 맞추어 가장 중요한 3개 시간대를 중점 분석합니다:
- 🌅 **아침 (09:00 ~ 10:00) [등교 시간]**: 하루 중 기온이 가장 낮고 쌀쌀한 시간대. 체감온도 및 찬바람 대비.
- ☀️ **점심 (12:00 ~ 13:00) [수·금 빠른 하교 시간]**: 기온이 상승하고 온화해지는 시간대. 가벼운 외투 탈의 고려.
- 🌆 **저녁 (16:00 ~ 17:00) [월·목 늦은 하교 시간]**: 일몰 전 기온이 급강하하며 찬바람이 부는 시간대. 재착용할 겉옷 대비.

### 3. 📅 요일별 스케줄 모드 (월·목 vs 수·금 자동 감지 및 원클릭 전환)
- **월·목 모드 (09:00 등교 ~ 17:00 하교)**:
  - 오후 수업이 있는 긴 하루 스케줄.
  - 아침 쌀쌀함 + 점심 포근함 + 저녁 기온 급락을 모두 커버하는 **"겉옷 탈착형 레이어드 룩"** 집중 추천.
- **수·금 모드 (09:00 등교 ~ 12:00 하교)**:
  - 점심 먹고 바로 하교하는 꿀스케줄.
  - 등교길 찬 공기만 버티면 점심에는 따뜻하므로, 벗어서 가방에 넣기 좋은 가벼운 셔츠/가디건 중심 코디 추천.
- **자율 스케줄 모드**:
  - 출발 시간과 복귀 시간을 10분 단위로 직접 키보드로 타이핑하여 맞춤 날씨 및 코디 분석 (예: 09:10 출발 ~ 16:40 복귀).

### 4. 📈 24시간 인터랙티브 기온 곡선 (Bézier Spline Chart)
- HTML Canvas 기반으로 오늘 하루의 24시간 온도 변화 곡선을 매끄럽게 시각화.
- 등교 시간(09시)과 하교 시간(12시 or 17시)이 강조 핀과 백그라운드 밴드로 하이라이트됩니다.
- 마우스 호버 시 해당 시간의 온도 및 날씨 상세 정보를 실시간 확인 가능.

### 5. 👔 스마트 OOTD 코디 추천 엔진
- **카테고리별 착장 분할**:
  - 🧥 **아우터 (Outerwear)**: 패딩, 코트, 트렌치코트, 자켓, 가디건, 바람막이 등
  - 👕 **상의 (Tops)**: 니트, 셔츠, 맨투맨, 후드티, 티셔츠, 발열내의 등
  - 👖 **하의 (Bottoms)**: 와이드 데님, 슬랙스, 치노 팬츠, 조거 등
  - 👟 **신발 (Shoes)**: 스니커즈, 로퍼, 더비, 러닝화, 레인부츠 등
  - 🎒 **소품 & 가방 (Accessories)**: 백팩, 메신저백, 머플러, 볼캡, **우산(비 예보 시 자동 경고 뱃지)** 등
- **개인화 옵션**:
  - 젠더리스 / 남성 / 여성 스타일 필터
  - 체감온도 보정 슬라이더 (더위를 많이 타는 체질 -2℃ vs 추위를 많이 타는 체질 +2℃)

### 6. 📋 등교 전 체크리스트 & 코디 요약 복사
- 당일 추천된 아이템(아우터, 상의, 하의, 신발, 우산 등)을 체크하며 아침 준비를 마칠 수 있는 인터랙티브 체크리스트.
- **"오늘의 코디 복사하기"** 버튼으로 카카오톡 단톡방이나 메모장에 바로 붙여넣기 가능한 포맷 지원.

## 🚀 로컬 실행 방법

이 프로젝트는 별도의 외부 npm 패키지 설치 없이 **Node.js 기본 내장 모듈**만으로 즉시 구동됩니다.

### 실행 명령:
```bash
# 개발 서버 시작 (포트 3000)
node server.js
# 또는
npm start
```

브라우저에서 `http://localhost:3000/` 으로 접속하시면 모든 기능을 이용하실 수 있습니다.

## 🛠️ 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript (ES Modules), Vanilla CSS
- **디자인/스타일**: Glassmorphism UI, Dark 테마, CSS Variables, 반응형 모바일 최적화
- **날씨 API**: Open-Meteo Forecast API (무료, API 키 불필요, 고정밀 hourly 데이터)
- **지오코딩**: HTML5 Geolocation API + BigDataCloud Reverse Geocode API
- **차트**: HTML5 Canvas 2D API (Custom Bézier Spline Renderer)
